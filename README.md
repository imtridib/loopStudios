# Loopstudios Landing Page

A responsive landing-page practice project inspired by the Frontend Mentor Loopstudios challenge. It includes a navigation menu, hero content, image-led sections, and local visual assets.

## Tech stack

- HTML5
- CSS3
- JavaScript
- SVG and image assets

## Run locally

Open `index.html` in a browser or use VS Code Live Server. Keep `style.css`, `app.js`, and the `images/` folder beside the HTML file.

## Status

This is a static front-end learning project based on a design challenge, not an official Loopstudios product website.
